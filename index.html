export ANTHROPIC_API_KEY="local"
claude --model deepseek-v4.1-flash

# PowerShell
$env:ANTHROPIC_BASE_URL="http://127.0.0.1:8787"; $env:ANTHROPIC_API_KEY="local"; claude --model deepseek-v4.1-flash
Python OpenAI SDK： 
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8787/v1",
    api_key="local"
)

response = client.chat.completions.create(
    model="glm-5.3-flash",
    messages=[{"role": "user", "content": "你好，请写一段快速排序。"}],
)
print(response.choices[0].message.content)

默认 8787，修改后需重启反代服务生效。

勾选后每次打开控制台会按上方端口与脱敏设置自动启动服务，无需手动点击「启动服务」。

自动处理敏感触发词，避免触发内容审核误报阻断。

内核热读生效，无需重启服务；Hermes 等客户端刷新模型列表后即可看到变化。不可用模型由运行时学习（上游 11102）与预标记共同判定。

默认关闭（静默无黑框）。建议直接在左侧「实时日志」页面内嵌查看调试日志。

点击右下角系统托盘图标可快速调出/隐藏控制台主窗口。

所有登录账号的 Token 统一保存在此文件中，与 WorkBuddy 桌面端完全解耦。

设置后，所有客户端（Claude Code / Codex CLI / Hermes 等）必须携带 Authorization: Bearer <密钥> 或 x-api-key: <密钥>， 否则返回 401 invalid api key。

⚠️ 修改后需重启内核生效（密钥在启动时以 --api-key 传入，不热加载）。 若将来监听非回环地址（0.0.0.0）暴露给局域网，必须设置密钥，否则服务处于无鉴权暴露状态。

日志写入 %LOCALAPPDATA%\workbuddy2api\converter.log， 可在「实时日志」页查看。修改后需重启内核生效。

⚠️ 隐私风险：开启后完整的提示词（Prompt）与模型响应正文会以明文写入日志文件， 仅建议在排查疑难问题且日志不外传时短时开启。该开关仅在日志级别为 trace 时实际生效（双闸门），排查完请及时关闭。

以下开关不写入 settings.json，需设置环境变量后重启内核才生效（当前运行中的内核不会热加载）：

  • WORKBUDDY2API_OPTIMIZE_CONTEXT=1 —— 启用 Codex 长上下文投影压缩（默认关闭；有损压缩，会截断历史与工具参数，按需开启）
  • WORKBUDDY2API_MAX_IMAGE_MB —— 远程多模态图片单图下载上限（默认 8；设为 0 完全禁用远程图片下载）
  • WORKBUDDY2API_MAX_BODY_MB —— 请求体大小上限（默认 16；超限在 ASGI 层按块熔断返回 413）
  • WORKBUDDY2API_USER_AGENT —— 覆盖出站 User-Agent（默认仿真官方客户端标识）
